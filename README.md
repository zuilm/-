# AI 岗位匹配

这是独立的 BOSS 直聘 AI 岗位匹配扩展。旧版海投、智能聊天、公司评论和会员登录功能已经从扩展中移除。

## 使用

1. 在 Chrome 扩展管理页加载或重新加载本目录，然后刷新 BOSS 直聘职位页。
   如果扩展更新时 BOSS 页面已经打开，旧页面的内容脚本会失效。筛选界面会提示刷新页面；点击“刷新页面并重新连接”后重新打开筛选。若失效发生在投递过程中，先核对 BOSS 会话的实际发送状态。
2. 点击浏览器扩展图标，保存 Markdown 简历、求职偏好、模型地址、模型名称和 API Key。模型地址可填写 OpenAI 兼容的 `/v1` 或 `/v1/chat/completions` 地址。
   设置保存在 Chrome 扩展的本机存储中，不会从 BOSS 网页读取。设置页可导出完整 JSON 配置文件，或导入 JSON 后核对并点击“保存设置”。导出文件含明文 API Key，请妥善保管。
   求职偏好建议每条单独一行，用“必须/只考虑/不考虑”等标明硬条件，用“优先”等标明加分项。分析详情会逐条显示偏好核对状态和岗位原文证据；未核实的必选条件不会进入“全选适配岗位”。修改偏好后需重新分析岗位。
3. 打开 BOSS 职位列表页，点击左下角“AI 筛岗位 · 根据我的简历”。
4. 在“AI JD 筛选”区点击“开始筛选当前岗位”。插件会先收集当前列表卡片，并尝试滚动加载更多岗位，直到达到批次上限或列表不再提供新岗位。此步骤只分析完整 JD，不发送消息。读取失败的岗位会显示原因，不会以职位卡片代替完整 JD 评分。
5. 查看右侧匹配证据与差距，勾选心仪岗位；也可以先勾选“仅看达到门槛且无明确冲突”，再点“全选适配岗位”，用符合条件且尚未投递的岗位替换旧勾选。在“投递已选岗位”区填写附件简历名称（有多份附件时），点击“一键投递已勾选岗位”。只有勾选的岗位会生成岗位专属文案并尝试发送已上传到 BOSS 的附件简历；点击后会逐个发送，无逐条确认。分数和冲突提示仅供你选择时参考。

筛选最多处理设置中的批次上限；如果 BOSS 没有继续加载新卡片，实际处理数会低于该上限。分析后的岗位可在当前页面勾选投递，超过 6 小时需重新筛选。附件简历必须预先上传到 BOSS。多份附件时填写准确的附件名称。

在要求扩展新标签页必须处于活动状态的内置浏览器中，读取 JD 和自动沟通会临时切换到新标签页；普通 Chrome 仍使用后台标签页。

首次沟通如果打开 BOSS 的简易弹窗，插件会核对岗位、公司和招聘者，再发送 AI 文案；此窗口没有附件入口时会将附件标为待处理。文案确认发送后会关闭简易沟通窗，并保留岗位页供核对附件状态。文案格式未通过校验时最多重新生成两次。岗位之间随机等待 1–2 秒。文案和附件都确认发送后会关闭本次创建的沟通页面；结果不明确时保留页面供核对。仅聊天窗口定位失败且未尝试发送 AI 文案的记录可再次运行，恢复时会按当前设置重新生成文案。

简历、求职偏好和岗位内容会发送到所配置的模型服务。模型分数只是文本匹配参考。筛选记录与自动沟通记录保存在本机扩展存储中，已尝试的岗位再次运行时会跳过；中断或未确认发送的岗位请手动检查会话，不要反复重发。“清除全部 AI 数据”会删除这些记录及简历、模型配置，清除后将无法再依靠历史记录防止重复沟通；已导出的 JSON 文件需要自行删除。

投递由你勾选并点击投递按钮决定。勾选“仅看达到门槛且无明确冲突”时，投递按钮只处理符合条件的已勾选岗位；取消筛选后，仍可自行决定是否投递低分或有明确冲突的岗位。
