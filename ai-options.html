02 · 模型服务

支持 OpenAI 兼容的 Chat Completions 接口。点击分析时，简历、偏好和岗位内容会发送到你配置的服务；API Key 保存在本机扩展存储中。

已预填 AccSpark 的 OpenAI 兼容地址。填写 `/v1` 时会自动补全为 `/v1/chat/completions`。每个未缓存岗位会调用一次模型接口，费用由服务商计收。

03 · 本机配置文件

保存设置会写入 Chrome 扩展的本机存储。JSON 文件用于备份或迁移；导入后请核对表单并再次保存。导出文件会明文包含简历、偏好和 API Key。

保存后，回到 BOSS 职位列表点击「AI 筛岗位」。
